# TOROS AUTO — Официальный сайт автосалона в Петропавловске

Премиальный лендинг автосалона **TOROS AUTO** (г. Петропавловск, Казахстан). Продажа проверенных автомобилей с пробегом, срочный выкуп, Trade-In, автокредитование и доставка авто под заказ.

🌐 **Демо онлайн**: [https://stanix228-ops.github.io/toros-auto/](https://stanix228-ops.github.io/toros-auto/)

---

## ⚡ Особенности и функционал

- 🎬 **Cinematic Hero**: Фоновое авто-видео с затемнением и парящими атмосферными частицами.
- 🚗 **Интерактивный каталог авто**: 
  - 9 проверенных автомобилей в наличии с реальными фотографиями и техническими характеристиками.
  - Поиск по названию/модели.
  - Быстрые фильтры по типу кузова (Кроссоверы, Седаны, Минивэны).
  - Сортировка по цене и году выпуска.
  - Детальная карточка авто с галереей, калькулятором и быстрым переходом в WhatsApp.
  - Полноэкранный Lightbox для просмотра фото авто.
- 🧮 **Интерактивный автокредитный калькулятор**: Динамический ползунок стоимости, расчет первоначального взноса, срока и ежемесячного платежа в KZT.
- 🔄 **3-шаговый мастер оценки Trade-In**: Быстрый расчет стоимости авто клиента с моментальной отправкой параметров оценщику в WhatsApp.
- 🗺️ **Темная интерактивная Яндекс Карта**: Точная геолокация автосалона (ул. Набережная, 19А, Петропавловск).
- 📱 **Прямая интеграция мессенджеров и соцсетей**: WhatsApp консультации и переход в Instagram `@toros_autotrade`.
- 💎 **Дизайн Dark Luxury**: Черный OLED фон, типографика Space Grotesk + Manrope, сбалансированные золотые и изумрудные акценты, векторные SVG-иконки.

## 🚀 Локальный запуск

```bash
# Клонировать репозиторий
git clone https://github.com/stanix228-ops/toros-auto.git

# Перейти в папку
cd toros-auto

# Запустить сервер
npm start
# или
node server.js
```

Сайт откроется по адресу: `http://localhost:3000`
